# 아산병원 프린터/드라이버 통합 마이그레이션 도구 (`v1.0.0-beta.1`) — 현장 E2E 통합 테스트 체크리스트

> **테스트 대상 파일:** `dist/Asan_Printer_Manager.bat`  
> **권장 진행 방식:** 구 PC(Windows 10) 1대 + 새 PC(Windows 11) 1대(또는 테스트 VM)에서 아래 시나리오를 순서대로 점검하고 `[ ]`를 체크합니다.  
> **이슈 발견 시:** 문서 맨 아래 **[실패 이슈 보고 양식]**에 TC 번호와 로그만 적어주시면 즉시 소단위 패치 → 재빌드 → 자동 검증으로 수정합니다.
