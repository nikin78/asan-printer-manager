# Asan Desktop Utility UI/UX Design System (Antigravity Agent Guide)

이 문서는 **사람용 소개서가 아니라 Antigravity 에이전트가 아산병원 현장 운영 도구를 바이브 코딩할 때 디자인·UX·품질을 100% 일관되게 유지하기 위한 실행 규격서**입니다.

* PowerShell 5.1 WinForms 실전 코드 템플릿은 필요 시 [winforms_ps51_patterns.md](./references/winforms_ps51_patterns.md)를 읽어 그대로 재사용하세요.
* 별도 UI 프레임워크(WPF, Electron, Web 등)를 쓰더라도 **1~6절의 컬러·대비·레이아웃·UX 라이팅·오류 처리 철칙은 동일하게 적용**합니다.

---

## 1. 절대 준수 철칙 (Non-Negotiable Iron Rules)

1. **저작권 로고 전면 금지:** 병원 공식 로고·심볼 이미지(PNG/ICO/SVG/Base64)를 절대 내장·복제하지 마세요. 대신 도구 성격에 맞는 **자체 벡터 심볼(GDI+ 등)**을 코드로 직접 그려 헤더 배지와 창 아이콘에 사용합니다.
2. **저가 사무용 모니터 기준 고시인성:** 연한 배경 위에 연한 헤더·연한 버튼(화이트 온 화이트, 연민트 헤더 + 연민트 행)을 배치하지 마세요. 상단 헤더(`#005658`)와 표 헤더(`#0B4F51`)는 **진한 딥 틸 + 흰색 굵은 글씨**로 강한 시각 기준점을 잡습니다.
3. **비활성 버튼은 0.1초 만에 구분 + 사유 툴팁 필수:**
   * 비활성 버튼은 **점선(`Dash`) 테두리 + 옅은 무채색(`#F1F3F3`) + 비굵은 연회색(`#94A0A2`)**으로 직접 렌더링합니다(WinForms 기본 `GrayText` 금지).
   * 모든 비활성 버튼은 마우스를 올렸을 때 **왜 비활성인지 + 어떻게 해결하는지** 툴팁으로 즉시 안내합니다(WinForms는 부모 컨테이너 `MouseMove` + `GetChildAtPoint` 라우팅 필수).
4. **모호한 표현·OS 하드코딩 금지:**
   * `오프라인` 단독 표기 금지 → **`사내망 · 서버 연결됨`** / **`사내망 연결 · 서버 미응답`** / **`사내망 미연결`**처럼 네트워크 상태임을 명확히 표기합니다.
   * 기존 PC가 항상 Windows 10이라고 단정하지 마세요. 탭·문구·분기는 Windows 10/11 공용으로 설계하고, 시작 탭은 OS만이 아니라 실제 작업 상태(매칭 백업 유무 등)로 지능 결정합니다.
5. **상용 UX 라이팅 원칙:** `※`, `★`, `▶`, `[버튼명]` 대괄호, 느낌표(`!`), 괄호 안 부가 설명 단문을 UI 문구에서 배제합니다. 강조는 색상·굵기·배지로, 부가 설명은 `ToolTip`이나 짧은 평서문으로 분리합니다.
6. **오류 발생 시 자동 리포트 구성 안내(온·오프라인 분기):** 수동 `오류 신고` 버튼 외에, 작업 중 오류가 발생하면 리포트를 자동 구성해 보낼지(사내망 연결 시) 또는 로컬 폴더에 저장할지(사내망 미연결 시) 즉시 묻고, 민감정보는 자동 마스킹합니다.
7. **DPI 100~150%·최소 창 크기(`960×640`)·균일 여백 철칙:**
   * 우측 컨트롤에 `Anchor=Right` 하드코딩 금지(`Dock` + `FlowLayoutPanel` + `RightToLeft` 스트립만 사용).
   * 테두리 있는 멀티라인 `TextBox`에 직접 `BorderStyle=FixedSingle`을 쓰지 말고, 반드시 **패딩 래퍼 패널(`New-PaddedTextBoxPanel`, 좌우 10~12px · 상하 5~8px)**로 감싸 텍스트가 칸 테두리에 붙지 않게 합니다.
   * 표 셀과 헤더는 좌우 `8px` 패딩(`34px` 헤더 / `32px` 행)을 기본으로 유지합니다.
8. **시각 감사 없이 완료 보고 금지:** UI 변경 후에는 자동 레이아웃 검증뿐 아니라 **실제 렌더링 스크린샷을 캡처해 에이전트가 직접 이미지로 확인**한 뒤 보고합니다.
9. **디자인 기조 변경 시 스킬 동시 동기화:** 앞으로 아산병원 툴의 GUI 디자인·여백·UX 원칙을 개선할 때마다 본 스킬(`SKILL.md`, `references/`)과 로컬 전역 스킬(`~/.gemini/config/skills/asan-desktop-ui`)도 반드시 함께 최신화합니다.

## 3. 표준 화면 아키텍처 (4영역 고정 셸)

모든 아산 현장 유틸리티는 아래 4영역 골격을 기본으로 합니다.

1. **Top — 2단 헤더 (`82px`):**
   * **1행 (`52px`, `#005658`):** 좌측 자체 GDI+ 벡터 심볼(`40×40`) + 앱 제목/1줄 부제 · 우측 네트워크 상태 배지 + `새로고침`(F5) + `오류 신고`
   * **구분선 (`2px`, `#F68B1F`):** 아산 오렌지 포인트 라인
   * **2행 (`28px`, `#EDF3F3`):** 좌측 `PC명 IP` · `OS명` · `서버 연결 요약` · 우측 식별값(예: `SID`) + 즉각 피드백 복사 버튼
2. **Inner Top — 조건부 치명 경고 배너 (`38px`, `#C0392B`, 기본 숨김):**
   * 작업을 차단하는 시스템 정책(WPP 등)이 감지될 때만 노출. 우측에 `조치 방법 안내` + `설정 바로 열기` 버튼 배치.
3. **Fill — 작업 영역 (`1040×720` 기본, `960×640` 최소):**
   * 복수 작업 흐름은 `OwnerDrawFixed` 번호형 탭(`1. ...`, `2. ...`, `3. ...`)으로 구성(활성 탭 흰 배경 + 상단 `4px` `#006769` 바, 비활성 탭 `#D9E7E6`, `Alt+1~N` 단축키).
   * 탭 내부가 다단계 흐름이면 좌측에 **`1단계` → `2단계` → `3단계`** 아산 그린 배지(`#006769`, 흰색 `8.5pt Bold`)로 시선을 고정합니다.
   * 중앙 `DataGridView`는 마지막 가변 열에 `AutoSizeMode = Fill`을 적용해 우측 빈 여백을 없앱니다.
   * 부가 도우미(인증 해결·특수 장비 등)는 평소 접어 두고, 관련 항목이 감지될 때만 자동 펼침 + 접힘 상태에서는 버튼에 미해결 건수(`도우미 (2)`)를 표시합니다.
4. **Bottom — 슬림 진행 상태 바 + 기본 접힘 상세 로그 (`38px` ↔ `128px`):**
   * 작업 공간을 넓히기 위해 상세 로그는 **기본 접힘(`상세 로그 보기`)**으로 시작합니다.
   * 진행 상태 텍스트는 대기 `#2F4244`, 작업 중 `#004D4F`, 오류 `#9E261C`로 색상을 구분합니다.

### 3-1. 여백·패딩 통일 규격 (Unified Spacing Scale)

칸과 텍스트 사이가 답답하게 붙지 않도록 전 화면에 동일한 여백 스케일을 강제합니다.

| 영역 | 표준 수치 | 비고 |
| :--- | :--- | :--- |
| 상단 헤더 · 메타 바 · 하단 바 좌우 패딩 | **`16px`** | 창 좌우 수직 정렬선 통일 |
| 메인 탭 컨테이너 / 탭 페이지 좌우 패딩 | **`12px`** / **`10px`** | 카드와 외곽선 간 균일 호흡 |
| 상단 상태 배너 (탭 1·탭 3 등) | 높이 **`40px`**, 좌측 `4px` 상태 바 + 내부 좌우 **`12px`** | 모든 탭의 상단 배너 형태 통일 |
| 정보 카드 (1단계 카드 · 스캐너 바 등) | 내부 좌우 **`12px`**, 상하 **`5~6px`**, 하단 간격 **`6~8px`** | 컨트롤과 테두리 최소 5px 확보 |
| 테두리 멀티라인 텍스트박스 (`New-PaddedTextBoxPanel`) | 래퍼 `FixedSingle` + 내부 **`Padding(10~12, 5~8, 8~10, 5~8)`** + 내부 `TextBox(BorderStyle=None)` | WinForms 기본 1px 붙음 현상 완전 제거 *(단, 960×640+WPP 극소 화면에서는 동적 `2px` 상하 압축 허용)* |
| `DataGridView` 열 헤더 / 데이터 행 | 헤더 **`34px`**(`WrapMode=False`), 행 **`32px`**, 셀/헤더 패딩 **`(8, 2, 8, 2)`** | 2글자 고정 열 최소 **`54px`**(줄바꿈 방지), 전체 열 너비+Fill 최소폭 합 `<= 930px` (`1040×720` 가로 스크롤 방지) |
| 미리보기 헤더 바 (탭 4 등) | 높이 **`28px`**, 좌우 패딩 **`12px`** | `GridHeadBg(#0B4F51)` 통일 |
| 버튼 간격 & 버튼 내부 여유 | 동그룹 **`6~8px`**, 이그룹 **`12~14px`**, 텍스트 좌우 최소 **`16px`** | 글자가 버튼 테두리에 닿지 않게 폭 확보 |

## 4. 버튼 위계 · 상태 피드백 · 인터랙션 규칙

### 4-1. 4계층 버튼 위계 (한 화면에 Primary는 1개만)

| Variant | 역할 | 스타일 | 예시 |

### 4-2. 인터랙션 UX 체크리스트

* **비활성 버튼:** `Sync-AllUiButtonStates` 한 곳에서 `Set-ButtonTipState`로 활성 여부와 사유 툴팁을 중앙 관리합니다. 작업 중(`IsBusy`)에는 모든 잠금 버튼이 `"현재 작업이 진행 중입니다. 완료 후 다시 시도해 주세요."`를 안내합니다.
* **침묵 클릭 금지:** `SID 복사` 같은 단발성 버튼은 클릭 시 `복사됨`으로 1.5초간 표시하고 하단 상태 바에 완료 문구를 띄웁니다.
* **오실행 방지:** 드롭다운(`ComboBox`)으로 대상을 바꿀 때는 `SelectionChangeCommitted`에서 즉시 재로드해 이전 항목이 실행되는 사고를 막습니다.
* **자연스러운 단축 동작:** 목록형 그리드는 더블클릭 기본 동작을 연결하고, 긴 열(`포트`·`드라이버`·`경로`·`상세 내용`)은 셀 `ToolTipText`로 전체 문장을 볼 수 있게 합니다. 검색 입력창 옆에는 비활성 연동 `지우기` 버튼을 둡니다.

## 6. 오류 처리 & 자동 리포트 규약

1. **단일 진입점:** 모든 비동기 작업의 오류 콜백(`!ok`)은 단순 `MessageBox` 대신 `Invoke-ErrorWithAutoReportPrompt`를 호출합니다.
2. **네트워크 자동 분기:**
   * 사내망·서버 연결 시: `"오류 진단 리포트를 자동으로 구성해 사내 리포트함으로 보낼까요?"` → 전송 창 자동 채움.
   * 사내망 미연결/서버 미응답 시: `"현재 사내 백업 서버에 연결되어 있지 않습니다. 이 PC의 로컬 폴더에 저장할까요?"` → 리포트 창 제목·안내 배너(오렌지)·버튼(`로컬 폴더에 저장`) 자동 전환 + 저장 완료 후 탐색기 폴더 열기 제안.
3. **보안 마스킹:** 리포트 생성 시 비밀번호·세션 자격증명·JSON 이스케이프 변형(`\u0026`, `\"` 등)을 반드시 `[REDACTED]`로 치환합니다.

## 7. 구현 후 필수 자가 검증 절차 (에이전트 완료 조건)

새 도구 제작 또는 UI 수정 후에는 아래 3단계를 모두 통과해야 작업 완료로 보고합니다.

1. **정적 검증:** PS 5.1 AST 파싱 에러 `0`, 금지 구문/클로저 캡처/`Anchor=Right` 위반 `0`, C# 5.0 `Add-Type` 컴파일 성공, Runspace 격리 검증 통과.
2. **자동 레이아웃 감사:** `-STA` 실제 WinForms 창에서 **`1040×720`**과 **`960×640`**(경고 배너·접이식 도우미 동시 펼침 포함) 전 탭 순회 → 버튼 겹침 `0`, 우측/하단 잘림 `0`, `DataGridView` 높이 `>= 80px`, 멀티라인 `TextBox` 높이 `>= 40px`, 비활성 버튼 사유 등록 확인.
3. **실제 픽셀 시각 감사:** `DrawToBitmap`으로 핵심 화면(사내망 연결/미연결, 비활성 버튼 포함 상태, `960×640` 최소 크기)을 PNG로 캡처한 뒤 에이전트가 직접 이미지 파일을 열어 글자 잘림·색상 뭉개짐·대비 부족·정렬 어긋남이 없는지 육안 확인합니다.
